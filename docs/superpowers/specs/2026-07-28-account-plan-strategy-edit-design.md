# Account Plan 策略正文编辑设计

## 目标

让销售人员直接在 Account Plan 详情页维护策略正文，同时避免现有完整更新接口重建产品、关系人和里程碑。

## 范围

可编辑字段：

- `businessGoal`：业务目标，必填
- `situation`：现状判断，可空
- `strategy`：核心策略，必填
- `successCriteria`：成功标准，必填

负责人、HCO、年度、产品、关系人和里程碑不在本编辑器范围内。关闭计划只读。

## 接口与领域规则

新增 `parseAccountPlanStrategyInput(value)` 纯函数，负责去除首尾空格和必填校验。

新增 `PATCH /api/account-plans/[id]/strategy`：

1. 校验 JSON 和四个字段。
2. 计划不存在返回 404。
3. 计划已关闭返回 409。
4. 只更新四个正文列。
5. 返回更新后的完整 Account Plan 详情结构。

现有 `PATCH /api/account-plans/[id]` 保持不变，继续服务完整计划编辑。

## 界面

客户策略卡片标题区增加“编辑策略”。点击后打开对话框，四个字段均使用多行文本框；保存期间禁用重复提交，失败保留内容并显示错误，成功关闭对话框、显示成功提示并刷新详情。

## 验收

- 活动计划可编辑四个字段。
- 保存不改变负责人、产品、关系人和里程碑。
- 关闭计划不显示编辑入口，接口也拒绝修改。
- 领域测试、lint、类型检查、构建和浏览器保存流程通过。
