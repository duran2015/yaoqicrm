# Pharma Sales P0 演示脚本

## 准备

```bash
npm install
npx prisma db seed
npm run dev
```

访问 `http://localhost:5618`。种子数据可重复执行，会恢复以下确定性场景。

## 演示身份

- 医药代表：张伟（YG1004）
- 进行中代表：陈静（YG1005）
- 明显落后代表：刘洋（YG1006）
- 地区经理：李强（YG1002）

## 主线一：月度覆盖到周计划

1. 切换到李强，打开“月度覆盖”，月份保持 `2026-07`。
2. 依次选择张伟、陈静和刘洋，展示 100%、53.8% 和 0% 三种达成状态。
3. 查看 A/B 级客户优先排列、目标次数、完成次数和剩余缺口。
4. 在刘洋的缺口客户上点击“加入周计划”。
5. 周计划编辑器自动打开并预选该医生；选择日期后保存草稿。
6. 返回月度覆盖，说明实际拜访提交后才会计入覆盖完成。
7. 切换到李强的“经理工作台”，查看团队达成率、落后人员和 A/B 级未覆盖客户下钻。

若要演示经理创建新计划，可在“月度覆盖”选择一个尚未生成计划的月份，设置 A/B/C/D 频次为 4/2/1/0 后点击“生成计划”。

## 主线二：计划到拜访

1. 切换到张伟，打开“周计划”。
2. 查看已批准计划和七天周日历；已执行项显示“已完成”。
3. 对待执行项点击“记录拜访”，确认医生和日期已经预填。
4. 表单中的“拜访前简报”展示历史拜访、未完成任务和样品历史。
5. 填写拜访结果和下一步计划，勾选生成结构化任务后提交。
6. 返回周计划，计划项变为已完成；进入“后续任务”查看新任务。

## 主线三：战略客户 Account Plan

1. 切换到李强，打开“客户策略”。
2. 查看三份 2026 Account Plan：
   - 苏州大学附属第一医院：里程碑全部完成，展示顺利推进。
   - 苏州市立医院：核心决策人中立且未覆盖，展示关系风险。
   - 苏州九龙医院：存在逾期开放里程碑，展示执行风险。
3. 进入任一计划，查看业务目标、现状判断、核心策略、成功标准和重点产品。
4. 在关键关系人区查看决策角色、支持态度和最近覆盖。
5. 在开放里程碑上点击“转为任务”，再进入“后续任务”验证 HCO、负责人、截止日期和 Account Plan 来源。
6. 返回计划，将另一条里程碑标记完成，确认计划进度更新。
7. 打开对应 HCO 详情，验证 2026 Account Plan 摘要和详情入口。
8. 返回经理工作台，查看计划平均进度、风险计划和逾期里程碑下钻。

若要演示新建，在“客户策略”点击“创建 Account Plan”，选择战略 HCO、重点产品、同院关键 HCP 和初始里程碑。非战略 HCO、跨院关系人及重复年度计划会被拒绝。

## 主线四：任务与复访

1. 使用张伟打开“后续任务”。
2. 找到高优先级逾期任务“补充最新 III 期研究文献”。
3. 点击“创建复访”，系统创建一次复访草稿并阻止重复创建。
4. 对另一条任务执行“完成”，切换筛选到“已完成”验证状态。

## 主线五：经理闭环

1. 切换到李强，打开“经理工作台”。
2. 查看待批计划、待评拜访、异常签到、逾期任务和待办辅导统计。
3. 从一条异常签到点击“创建辅导”。
4. 填写行动要求与截止日期并保存。
5. 在辅导行动区点击“标记完成”，统计随之更新。
6. 周计划审批和拜访评定通过工作台链接进入原业务页面完成。

## 主线六：样品库存

1. 切换到张伟，打开“样品库存”。
2. 库存表按产品和批次展示领用、发放和当前余额，下方展示完整流水。
3. 点击“库存操作”，分别演示领用入库和退回。
4. 选择“盘点”，输入实存数量；系统自动生成正或负调整流水。
5. 点击全局“记录拜访”，添加样品并勾选“已确认签收”后提交。
6. 返回库存页验证余额和发放流水。任何导致负库存的操作会被拒绝。

## 主线七：会议跟进

1. 打开“会议”，可看到一场进行中城市会和一场已结束科室会。
2. 点击“创建会议”，填写名称、时间、地点并邀请 HCP，保存为草稿。
3. 展开草稿会议并点击“开始会议”。
4. 对受邀医生执行签到或缺席，随后结束会议。
5. 输入统一的跟进标题和截止日期，为已签到医生批量生成任务。
6. 进入“后续任务”验证会议来源任务；重复生成会跳过同名未完成任务。

## 主线八：活动到销售结果

1. 切换到李强，在经理工作台查看 7 月团队目标金额、实际金额、达成率和环比。
2. 点击“进入销售分析”，查看 2026-02 至 2026-07 的目标与实际趋势。
3. 依次切换产品、HCO、代表三个维度，点击明细行完成下钻。
4. 在详情中并排查看销售金额、拜访次数、覆盖 HCP、会议和已完成 Account Plan 里程碑。
5. 强调页面展示的是同期“活动关联”，不宣称活动直接导致销量变化。
6. 进入“导入 CSV”，下载示例；非法文件会逐行报错且无法确认，合法文件预览后按业务键覆盖导入。
7. 演示结束后运行 `npx prisma db seed`，恢复固定六个月数据。

固定数据包含三类故事：稳定活动伴随持续增长、活动增加后销量延迟改善、覆盖不足且持续未达。

## 主线九：批准资料到拜访追溯

1. 打开“产品”，展开重点产品的“合规资料”。
2. 对比当前有效、即将到期和已停用历史版本，查看版本、批准编号、话术摘要和有效期。
3. 点击“新建版本”，保存一条资料草稿；草稿可批准或直接停用。
4. 点击全局“记录拜访”，选择医生和产品。
5. 只勾选该产品下当前有效且已批准的资料并提交拜访。
6. 打开对应 HCP 360，在拜访历史中核对资料标题、版本和批准编号快照。
7. 后续停用资料不会改写历史拜访快照。

## 演示边界

- 当前身份切换用于演示，不代表生产认证或权限。
- 样品签收是演示确认字段，不具备法律电子签名效力。
- 产品资料使用外部演示链接，不包含文件托管、电子审批或下载鉴权。
- SQLite、桌面 Web 和固定演示数据适用于宣传演示，不代表生产部署方案。
- WorkBuddy/MCP 串联属于下一阶段。
